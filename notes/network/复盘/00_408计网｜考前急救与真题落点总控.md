## 近 5 年（2022—2026）命题趋势与五条高频主轴

1. **链路层 CSMA/CD、CSMA/CA 与 VLAN 隔离**：CSMA/CD 连续考查经 Hub 延时扣减（2022-T47）及二进制指数退避上限截断（2023-T36、2025-T35）；CSMA/CA 转向帧间间隔起始点切分——隐藏站收 CTS 后设 NAV（2024-T36）及从开始发送 DATA 到确认收到（不含 DIFS，2026-T35）；802.11 上下行三地址（2022-T47）与交换机端口 VLAN 隔离（2024-T35、2026-T36）已成高频常规题。
2. **GBN / SR 可靠传输与信道利用率模型**：重点对比同信道 3 比特序号下的协议选型关系（2023-T35：$U_1 \le U_3 \le U_2$）、SR 单帧超时后窗口停滞与重传追踪（2024-T37）、卫星高传播时延场景下由利用率反推最小窗口与序号比特数（2025-T47）。
3. **IPv4 分片、CIDR 划分/聚合、NAT 与多域路由**：子网划分题强调已有主机反推掩码定位（2025-T47）与均分大块定位（2026-T39）；链路状态算法开始结合“断链重算最短路径树 + 充分路由聚合”考查表项变化（2026-T37）；NAT 深入到 `/30` 推对端（2023-T38）及修改 UDP 源端口与重算检验和（2025-T37）；多 AS 路由协议综合（RIP 扩散轮次、eBGP/iBGP/UPDATE、热土豆，2024-T47）成为 9 分大题范式。
4. **TCP 序号、窗口在途扣除、慢开始与挥手时延**：2022–2026 年连续考察 `cwnd` 逐 ACK 线性/指数演化与 `swnd = min(cwnd, rwnd)` 封顶（2022-T38、2023-T47、2025-T38、2026-T47），且 2025-T38 与 2026-T47 均重点检验“扣除已发未确认在途字节”和“确认号对应第几段数据”；连接释放时延严格区分主动关闭含 `2MSL`（2022-T39、2024-T38）与被动方 `1.5 RTT` 或仅计文件收全确认时刻（2023-T47、2026-T47）。
5. **ARP / DHCP / DNS / HTTP 全过程跨层联动**：要求从开机或空白缓存出发，完整串起 `DHCPDISCOVER`/`DHCPREQUEST`（源 `0.0.0.0`、目的 `255.255.255.255`、广播 MAC 全 F 透传）、ARP 解析、DNS 查 IP、TCP 建连慢开始叠加 HTTP 请求（2022-T40/T47、2024-T40、2025-T36、2026-T40）。

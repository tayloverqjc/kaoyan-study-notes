# 1.1 数据结构的基本概念

## 1.1.1 基本概念和术语 【💤 可跳过｜冲刺期直接跳过不看】

### 这一节要解决什么问题

同样是“学生成绩”，为什么可以把一条记录看成元素，又可以把学号和成绩看成更小的部分？算法研究的对象与它的组织方式怎样区分？

| 概念 | 说明 | 例子与辨析 |
|---|---|---|
| **数据** | 信息的载体，是能输入计算机并被识别和处理的符号集合 | 数字、字符等；数据是计算机程序加工的原料 |
| **数据元素** | 数据的基本单位，通常作为一个整体考虑和处理 | 一条学生记录 |
| **数据项** | 构成数据元素的不可分割的最小单位 | 学号、姓名等是该记录的数据项；它与单个字符不是固定的一一对应关系 |
| **数据对象** | 具有相同性质的数据元素的集合，是数据的一个子集 | 整数集合、某班全部学生记录 |
| **数据类型** | 一个值的集合及定义在该集合上的一组操作的名称 | 原子类型的值不可再分；结构类型的值可分解为若干成分 |
| **抽象数据类型 ADT** | 数学模型及定义在该模型上的一组操作 | 着重说明取值、逻辑关系和可进行的操作，不以某种具体存储实现为定义前提 |

## 1.1.2 数据结构三要素 【📌 扫一眼｜确认“我还会”就过】

数据结构是相互之间存在一种或多种特定关系的数据元素的集合。分析时必须同时注意**逻辑结构、存储结构和数据的运算**。

### 一、数据的逻辑结构 【📌 扫一眼｜确认“我还会”就过】

逻辑结构描述**数据元素之间的逻辑关系**，从逻辑关系的角度描述数据，独立于计算机中的具体存储方式。

| 结构 | 元素之间的关系 | 例子 |
|---|---|---|
| 集合 | 除同属于一个集合外，没有其他结构关系 | 一组互不关联的记录 |
| 线性结构 | 元素之间是**一对一**的关系 | 线性表、栈、队列、串 |
| 树形结构 | 元素之间是**一对多**的层次关系 | 树、二叉树 |
| 图状结构 | 元素之间是**多对多**的关系 | 图 |

按本书的分类，**集合、树形结构和图状结构属于非线性结构**；线性结构中数据元素之间是一对一关系。

> [!important] 易混辨析
> <mark>线性表是一种逻辑结构</mark>，顺序表和链表是它的不同存储表示。同一种逻辑结构可以采用不同存储方式；不能因为元素在物理上相邻，就断定它们在逻辑上一定相邻。 `[真题·2009-T01]`

### 二、数据的存储结构 【📌 扫一眼｜确认“我还会”就过】

存储结构也称**物理结构**，是数据结构在计算机中的表示，既包括数据元素的表示，也包括元素之间关系的表示。

| 方式 | 表示关系的方法 | 主要特点 |
|---|---|---|
| **顺序存储** | 逻辑相邻的元素存放在物理位置相邻的存储单元，邻接关系由位置体现 | <mark>支持按位置随机存取</mark>；需要相应的连续空间 `[真题·2023-T01]` |
| **链式存储** | 通过指针等链接信息表示元素间关系；逻辑相邻的元素在物理上不必相邻 | 便于按链接组织和插删，通常需额外链接域；按序号查找一般从头遍历 |
| **索引存储** | 存储元素信息的同时建立索引表 | 借助关键字和地址检索；索引要占空间并在更新时维护 |
| **散列存储** | 根据关键字直接计算存储地址 | 查找、插入和删除通常较快；不同关键字可能发生冲突，需处理冲突 |

链式存储不要求**不同结点之间**地址连续，但每个结点内部的数据域、指针域仍需按该结点类型的布局存储。链式存储的结点也可能碰巧相邻，因此不能说“结点地址一定不连续”。

### 三、数据的运算 【📌 扫一眼｜确认“我还会”就过】

- **运算的定义**针对逻辑结构，说明运算的功能；例如线性表定义按位查找、插入和删除。
- **运算的实现**针对存储结构，描述具体操作步骤；相同的逻辑操作，在顺序表和链表上的实现和代价可能不同。
- 算法设计要考虑逻辑结构，算法实现要依托所选的存储结构。不同数据结构也可能采用相同的逻辑结构和存储结构，但运算的定义或用途不同。

# 1.2 算法和算法评价

## 1.2.1 算法的基本概念 【📌 扫一眼｜确认“我还会”就过】

算法是对特定问题求解步骤的一种描述，是由若干指令构成的有穷序列。教材列出五个重要特性：

| 特性 | 具体要求 |
|---|---|
| **有穷性** | 算法执行有限步后结束，每一步都能在有限时间内完成 |
| **确定性** | 指令含义明确；对相同输入，确定性算法的执行和输出确定 |
| **可行性** | 每一步可以通过已经实现的基本运算有限次执行完成 |
| **输入** | 可以有零个或多个输入 |
| **输出** | 至少有一个输出，且与输入存在特定关系 |

> [!warning] 特性与设计目标
> **正确性、可读性、健壮性、高效率与低存储量需求**是设计优秀算法的重要目标；不要把“至少有一个输入”或“可读性”误写成上述五个基本特性。

## 1.2.2 算法效率的度量 【🔥⚡ 必背+避坑｜停下来默背 1 遍 + 精读 1 分钟】

### 一、时间复杂度 【🔥⚡ 必背+避坑｜停下来默背 1 遍 + 精读 1 分钟】

- 语句**频度**指语句执行的次数；选择基本运算后，可把执行次数写成问题规模 $n$ 的函数 $T(n)$。
- 大 $O$ 记号刻画渐近上界：存在正常数 $c,n_0$，当 $n\ge n_0$ 时，$0\le T(n)\le c f(n)$，记为 $T(n)=O(f(n))$。做题通常根据具体执行次数给出紧确的增长阶；**不能把大 $O$ 的形式定义理解为运行次数必然恰好等于该函数**。
- **最好、最坏、平均**针对相同规模下不同输入。教材通常用最坏时间复杂度作为评价指标；计算平均值时必须明确输入及其概率。

| 分析对象 | 计算方法 | 典型结果 |
|---|---|---|
| 顺序执行 | 各部分频度相加，<mark>按加法规则取增长较快项</mark> | $O(n)+O(n^2)=O(n^2)$；$O(m+n)=O(\max(m,n))$ `[真题·2013-T01 / 2026-T06]` |
| 独立嵌套 | <mark>外层执行次数乘以内层次数</mark> | $n$ 次中各执行 $n$ 次，得 $O(n^2)$；$k\le n$ 倍增乘 $n$ 得 $O(n\log n)$ `[真题·2014-T01]` |
| 倍增或减半 | 写出 $1,2,4,\ldots$ 或 $n,n/2,\ldots$，<mark>由幂次关系解出循环次数</mark> | $O(\log n)$ `[真题·2011-T01]` |
| 内层次数随外层改变 | <mark>逐层求和不能机械相乘</mark> | $1+2+\cdots+n=O(n^2)$；$1+2+4+\cdots<2n$，故为 $O(n)$ `[真题易错·2022-T01 / 2025-T01]` |
| 累加到阈值 | 若第 $t$ 次后累加为 $1+\cdots+t$，令其与 $n$ 比较 | $t(t+1)/2$ 达到 $n$ 或 $(x+1)^2\le n$ 均为 $O(\sqrt n)$ `[真题·2017-T01 / 2019-T01]` |
| 递归 | 写递推式，同时数清<mark>每次调用次数与额外工作</mark> | $T(n)=T(n-1)+O(1)$ 为 $O(n)$；$T(n)=T(\lfloor n/2\rfloor)+O(1)$ 为 $O(\log n)$ `[真题·2012-T01]` |

> [!important] 真题中的几种循环不要混算
> - **2011**：变量从常数开始每次乘 2，达到与 $n$ 同阶的阈值需 $O(\log n)$ 次。 `[真题·2011-T01]`
> - **2014**：外层倍增而内层每次都完整执行 $n$ 次，总计 $O(n\log n)$。 `[真题·2014-T01]`
> - **2017、2019**：分别根据等差累加达到 $n$、平方达到 $n$ 建立不等式，均得到 $O(\sqrt n)$。 `[真题·2017-T01 / 2019-T01]`
> - **2022**：外层取 1、2、4……，内层执行次数随外层值增加，总次数是几何级数，结果为 $O(n)$，不是 $O(n\log n)$。 `[真题易错·2022-T01]`
> - **2025**：外层 $i$ 到 $\sqrt n$，内层执行 $i$ 次，求和为 $1+2+\cdots+\lfloor\sqrt n\rfloor=O(n)$。 `[真题易错·2025-T01]`

- `【⚡ 真题补丁｜2013-T01 / 2026-T06】` 双参数线性相加时，`O(m + n)` 等价于 `O(max(m, n))`（2013-T01 两链表合并、2026-T06 邻接表求入度 `O(max(|V|, |E|))`）。

常见增长速度从小到大可记为：常数、对数、平方根、线性、线性对数、平方、多项式高次、指数、阶乘。比较时仍要先明确变量和定义域。

### 二、空间复杂度 【🔥 必背｜停下来默背 1 遍】

空间复杂度表示算法在运行过程中所需**额外存储空间**随问题规模变化的数量级，记为 $S(n)=O(g(n))$。应区分输入本身占用的空间与算法额外申请的辅助空间：

- 固定个数的辅助变量通常为 $O(1)$；<mark>原地工作是指额外空间为常数阶</mark>，并非不占用任何存储空间。 `[真题·2009-T42 / 2010-T42 / 2011-T42 / 2013-T41 / 2016-T43 / 2019-T41 / 2020-T41 / 2025-T41]`
- 需要长度与 $n$ 成正比的辅助数组时，额外空间为 $O(n)$。 `[真题·2018-T41]`
- 递归必须考虑**同时存在的调用栈帧数**。例如每层只用常数辅助量、递归深度为 $n$ 时为 $O(n)$；深度为 $\log n$ 时为 $O(\log n)$。

# 选择题快速判断结论

- 逻辑结构不依赖具体存储方式；同一逻辑结构可以有不同的物理表示。
- 算法应有穷、确定、可行；输入可为零，输出至少一个。
- $O(1)$ 辅助空间表示额外空间不随 $n$ 增长，并非算法不需要存储空间。
- 分析复杂度要先看循环范围、每次如何变化和内外层依赖关系；递归要把调用次数与栈深分开。

## 01｜三类典型嵌套循环的时间复杂度（2014 / 2022 / 2025-T01）

问题：请口述以下三段代码的紧确时间复杂度并说明求和过程：① `for(k=1; k<=n; k*=2) for(j=1; j<=n; j++)`；② `for(i=1; i<n; i*=2) for(j=0; j<i; j++)`；③ `for(i=0; i*i<n; i++) for(j=0; j<i; j++)`。

> [!success]- 正确解释
> - **① 独立嵌套**：外层 $\log_2 n$ 次、内层恒 $n$ 次，总次数 $n\log_2 n = O(n\log n)$（2014-T01）。
> - **② 外层倍增内层跟 `i`**：总次数为 $1+2+4+\dots+2^{k-1}=2^k-1 < 2n$，结果为 **$O(n)$** 而非 $O(n\log n)$（2022-T01）。
> - **③ 外层平方根内层跟 `i`**：外层至 $\lfloor\sqrt n\rfloor$，内层求和为 $0+1+2+\dots+\lfloor\sqrt n\rfloor \approx n/2$，结果为 **$O(n)$**（2025-T01）。

## 02｜双参数复杂度化简与递归栈深（2012-T01 / 2013-T01 / 2026-T06）

问题：为什么 `O(m + n)` 在选项中常写成 `O(max(m, n))`？递归求 `fact(n)` 即使未开数组，空间复杂度为什么仍不是 `O(1)`？

> [!success]- 正确解释
> - **双参数合并**：因为 $\max(m,n) \le m+n \le 2\max(m,n)$，两者同阶，故 $O(m+n)=O(\max(m,n))$（2013-T01）与 $O(|V|+|E|)=O(\max(|V|,|E|))$（2026-T06）完全等价。
> - **递归空间**：递归调用会在系统栈同时压入至多 $n$ 层活动记录，因此时间 $O(n)$ 且空间复杂度亦为 $O(n)$（2012-T01）。

## 03｜原地工作与逻辑/存储分离（2009-T01 / 2010-T42）

问题：“原地工作”算法意味着不需要任何内存空间吗？如果元素在内存中物理相邻，能否断定它们在逻辑上也相邻？

> [!success]- 正确解释
> - **原地工作含义**：指算法所需的**额外辅助空间**相对于问题规模 $n$ 为常数 $O(1)$，不随 $n$ 增长。
> - **逻辑与物理边界**：不能断定。例如散列表、静态链表中的元素物理相邻但逻辑上并不一定相邻；同一线性逻辑结构既可顺序存储也可链式存储。
